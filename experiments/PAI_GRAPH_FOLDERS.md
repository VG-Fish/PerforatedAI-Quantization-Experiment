# PerforatedAI graph folders

This index lists every folder under `experiments/` that currently contains a
PerforatedAI-generated PNG, SVG, or PDF. Raw PAI folders contain the complete
run output; `pai_plots` folders are copies stored beside benchmark artifacts.
Quantized descendants normally reuse their FP32 source topology and therefore
do not have separate graph folders.
